# ELAN Quantum v0.5

AI Investment Platform para análisis cuantitativo, riesgo y backtesting.

## Novedades v0.5

- Risk Engine independiente.
- VaR y CVaR históricos al 95% y 99%.
- Volatilidad anualizada y drawdown máximo.
- Matriz de correlaciones.
- Contribución de cada activo al riesgo.
- Tamaño orientativo de posición según presupuesto de riesgo.
- Dashboard renombrado a ELAN Quantum.

## Instalación en Windows

1. Copiar el contenido sobre la carpeta del proyecto.
2. Ejecutar `update_to_v04.bat`.
3. Confirmar que todos los tests pasan.
4. Ejecutar `start_windows.bat`.

Herramienta educativa. No constituye asesoramiento financiero.
